# Pashu-Parvah AI 🐾

**Pashu-Parvah AI** is an AI-driven livestock health monitoring and early disease outbreak tracking platform designed to support farmers and veterinary healthcare workers.

## Key Features

- **Disease Reporting & Diagnostics**: Log animal symptoms and report potential disease outbreaks in real-time.
- **Alerts & Outbreak Mapping**: Live disease alerts and village hotspot tracking for proactive containment.
- **Digital Health Records**: Maintain digital health profiles and history for registered livestock.
- **Field-Ready UI**: Designed for simple navigation in rural and low-connectivity environments.

## Tech Stack

- **Frontend**: React, TypeScript, Tailwind CSS
- **Build Tool**: Vite
- **Routing**: TanStack Router
